# DakCoder — Bug Register

Compiled 2026-09-02 from a full adversarial audit. Confidence levels:
**REPRODUCED** = demonstrated by an executable script against the real modules
(scripts listed in `TEST_PLAN.md`); **CODE-PROVEN** = the defect is fully visible
in the code path cited; **LIKELY** = mechanism proven, trigger environmental.
Full mechanism/evidence for every row is in `AUDIT.md`.

ID prefixes: **L** = agent loop/context/runtime (`apps/agent`), **TL/GT/RG** =
tools/gate/registry, **SH** = shared libs, **GW** = gateway, **EXT** = VS Code
extension.
